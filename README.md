## Featured work

### [Multi-Factor Long/Short Equity Strategy](https://github.com/quantraunak/ls-multifactor-research)
Systematic long/short U.S. equity strategy — LightGBM cross-sectional ranking, Ledoit-Wolf shrinkage covariance, volatility targeting, and dollar/beta-neutral convex optimization.

**35.3% CAGR · 1.46 Sharpe (95% CI [0.90, 2.07]) · −24.7% max drawdown**, 2010–2024, walk-forward with purged CV, costs and slippage included.

[Results dashboard](https://quantraunak.github.io/ls-multifactor-research/) · [Repo](https://github.com/quantraunak/ls-multifactor-research)

[Paper](https://github.com/quantraunak/tot-resampled-thought-trees/blob/main/docs/paper.pdf) · [Code](https://github.com/quantraunak/tot-resampled-thought-trees)
